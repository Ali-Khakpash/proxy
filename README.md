# Relay با Vercel (معادل relay-worker با Cloudflare)

همان منطق ریله: هر درخواستی که به این پروژه برسد، عیناً (متد + هدرها + بدنه) به آدرس
واقعی سرویس فوروارد می‌شود و پاسخ هم عیناً برمی‌گردد. کلید API همچنان از خود افزونه
فرستاده می‌شود؛ این پروژه فقط رد و بدل می‌کند و ذخیره‌اش نمی‌کند.

بر خلاف Cloudflare، اینجا ساده‌ترین راه دیپلوی از طریق یک ریپازیتوری گیت‌هاب است
(نه پیست مستقیم کد در مرورگر).

## دیپلوی (برای Gemini)

1. یک ریپازیتوری تازه در [github.com](https://github.com) بسازید (خصوصی هم می‌تواند باشد).
2. دو فایل همین پوشه را داخلش بگذارید، دقیقاً با همین مسیر:
   - `api/[...path].js`
   - `package.json`
3. به [vercel.com](https://vercel.com) بروید، با همان حساب گیت‌هاب وارد شوید.
4. **Add New… → Project** را بزنید، ریپازیتوری بالا را انتخاب کنید و **Deploy** را بزنید.
   نیازی به تغییر هیچ تنظیمی نیست؛ Vercel خودش فایل زیر `api/` را به‌عنوان تابع سرورلس تشخیص می‌دهد.
5. بعد از پایان دیپلوی، آدرسی شبیه `https://your-project.vercel.app` می‌گیرید.
   **نکته‌ی مهم:** چون تابع زیر پوشه‌ی `api/` است، Base URLی که در تنظیمات افزونه می‌گذارید
   باید با `/api` تمام شود، یعنی: `https://your-project.vercel.app/api`

## دیپلوی برای OpenAI (اختیاری)

همان ریپازیتوری یا یک ریپازیتوری جدا بسازید، فقط در `api/[...path].js` این خط را عوض کنید:

```js
const UPSTREAM_BASE = 'https://api.openai.com/v1';
```

و در Vercel یک پروژه‌ی جدا از همان ریپازیتوری بسازید (یا در پنل پروژه از تب Settings آدرس
ریپازیتوری/برنچ را عوض کنید).

## تغییر کد بعد از دیپلوی

هر بار که فایل `api/[...path].js` را در گیت‌هاب ویرایش/کامیت کنید، Vercel خودش دوباره
دیپلوی می‌کند (چند ده ثانیه طول می‌کشد). نیازی به کار دستی دیگری نیست.

## تنظیمات افزونه

در وردپرس، تنظیمات ← AI Advisor:
- **Base URL** = آدرس Vercel + `/api` (طبق قدم ۵)
- **کلید API** = کلید واقعی همان سرویس (Gemini یا OpenAI)
- **کلید Relay** = فقط اگر `RELAY_SECRET` را در کد پر کردید، همان مقدار را اینجا هم بگذارید

## نکته‌ی امنیتی

اگر `RELAY_SECRET` را خالی بگذارید، هرکسی که آدرس این پروژه را پیدا کند می‌تواند از آن
به‌عنوان یک پراکسی به سمت Gemini/OpenAI استفاده کند. برای بستن این مسیر، مقدار
`RELAY_SECRET` را در کد پر کنید، کامیت/دیپلوی کنید، و همان مقدار را در فیلد «کلید Relay»
افزونه هم وارد کنید.
